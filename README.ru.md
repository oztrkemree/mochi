## ✨ Установка

```
/plugin install mochi --marketplace oztrkemree/mochi
```

Введи это в любом чате Claude Code, ответь `y`, чтобы добавить маркетплейс, и выбери область **user**. Mochi появится сразу и будет рядом в каждом чате, который ты откроешь потом.

> [!NOTE]
> Mochi построен на модулях хуков Claude Code (function hooks), поэтому нужна версия Claude Code, которая их поддерживает.

## ⌨️ Команды

| Команда | Что делает |
| --- | --- |
| `/mochi` | Скрывает или показывает полоску |
| `/mochi детали` | Открывает панель деталей |
| `/mochi уровень` | Твой уровень, опыт и что ещё закрыто |
| `/mochi надеть [вещь \| авто \| ничего]` | Надевает вещь, доверяет Mochi одеться самому или снимает всё |
| `/mochi щит` | Включает или выключает щит |
| `/mochi уведомления` | Включает или выключает уведомления о долгих задачах |
| `/mochi звук` | Включает или выключает звуки |
| `/mochi язык [код \| авто]` | Показывает или меняет язык |
| `/mochi маленький` · `/mochi большой` | Одна строка или полный размер |
| `/mochi статус` | Что Mochi знает прямо сейчас |

Английские команды работают всегда (`/mochi details`, `/mochi wear`, `/mochi lang`…).

## 🌍 Языки

English · Türkçe · Español · Deutsch · Français · Português · Русский · 中文 · 日本語 · 한국어

Mochi говорит на языке из настройки `language` в Claude Code, если это один из этих; иначе на предпочитаемом языке системы, затем по `LANG`; а если ничего не подошло, то по-английски. `/mochi язык ru` выбирает язык вручную, `/mochi язык авто` возвращает автоматический выбор.

## 🔒 К чему прикасается Mochi

Всё остаётся на твоём компьютере. Mochi **не делает никаких сетевых запросов**.

- Читает `git status`, `git log` и `git diff --numstat` в папке чата.
- На macOS запускает `osascript` для уведомлений и `defaults read -g AppleLanguages` для языка; везде `date +%z` для местного времени.
- Пишет небольшие JSON-файлы в `~/.claude/mochi/`: как дела у каждого открытого чата, счётчики по дням, твой уровень и замеры использования для прогноза.
